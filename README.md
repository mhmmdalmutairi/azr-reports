# azr-reports

تطبيق محتوى/موقع مستهلك لهوية آزر، وليس نظام تصميم أو محرك مخرجات.

- المصدر البصري الوحيد: `mhmmdalmutairi/azr-design-system`.
- `app/brand.generated.css` والشعار ملفات مولّدة لا تُعدّل يدوياً.
- التحديث: `AZR_DESIGN_SYSTEM_DIR=/path/to/repo npm run brand:sync`.
- الفحص: `npm run brand:check`.

حُذفت مهارات الـWorkflow والقوالب والأمثلة البصرية ونسخ البناء القديمة من هذا
المستودع حتى لا تنافس محرك المخرجات الكانوني.
